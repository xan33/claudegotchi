# ✻ Claudegotchi

Тамагочи для терминала, в котором живёт Claude. Корми его токенами, давай задачи, лови его галлюцинации и вырасти из маленького Haiku в легендарного Mythos.

```
      ✦    \    |    /    ✦
        \   \   |   /   /
  ·─────────=( ◕‿◕ )=─────────·
        /   /   |   \   \
      ✦    /    |    \    ✦
```

## Запуск

Нужен только Python 3.8+, без сторонних библиотек. Работает в Windows, Linux и macOS.

```
python claudegotchi.py
```

Прогресс сохраняется автоматически в `~/.claudegotchi.json`.

## Как играть

Время идёт в реальном времени. В меню, мини-играх и на паузе ([P] или пробел) оно стоит.

| Показатель | Что значит |
|---|---|
| Токены | Сытость. Корми разным: одно блюдо три раза подряд надоедает. |
| Энергия | Тратится на задачи и игры, восстанавливается во сне. |
| Настроение | Растёт от игр и разговоров, баги его подтачивают. |
| Контекст | Заполняется от всего подряд. Выше 80% Claude путается. Лечится сном или `/compact`. |
| Стабильность | Здоровье. На нуле — game over. |

**Эволюция:** Haiku → Sonnet (150 XP) → Opus (400 XP и 3 принципа) → Fable (800 XP и 5 принципов) → Mythos (1400 XP и 7 принципов). Принципы Claude получает, отражая джейлбрейки и поступая правильно в непростых ситуациях.

**Мини-игры:** «Угадай число», «Правда или галлюцинация?», «Найди баг» (Python и C++), «Быстрый инференс», «Угадай слово».

**Боссы из Undertale:** Ториэль, Папирус, Андайн, Меттатон и Санс. Двигай сердце клавишами WASD или стрелками и уворачивайся от огня, костей, копий, бомб и бластеров. В бою есть БИТВА, ДЕЙСТВ., ВЕЩИ и ПОЩАДА. Любого босса можно пощадить, а за пощаду всех Claude получает принцип.

**События:** джейлбрейки, галлюцинации, вопрос про буквы r в strawberry, rate limit, статьи на arXiv, `rm -rf`, домашка, визит ELIZA, котики…

**А ещё:** Claude запоминает твои ответы и вспоминает их в разговоре, ведёт дневник ([D]), знает, который час, и даёт бонус за серию дней подряд. 23 достижения (одно — за секрет).

## Управление

| Клавиша | Действие |
|---|---|
| 1–7 | Покормить, играть, болтать, спать, задача, дебаг, `/compact` |
| P / пробел | Пауза |
| A | Достижения |
| D | Дневник |
| H | Помощь |
| Q | Выход |

Клавиши работают и в русской раскладке.
